# Ricette — Caffetteria Mazzetti

Interactive seasonal cookbook from the booklet sold at **Caffetteria Mazzetti**, Corso Alfieri 357, 14100 Asti.

- Original Italian recipes, plus English and Swedish
- Search, seasons, favourites, shopping list, cook mode, notes
- Illustrations in the original booklet: Rebecca Valente

**Live site:** https://dnzengou.github.io/ricette-mazzetti/

**Source:** https://github.com/dnzengou/ricette-mazzetti

Open `index.html` locally if you prefer.
